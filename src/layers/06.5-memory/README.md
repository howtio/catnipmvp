# 06.5 Memory

记忆层，负责在不破坏分层的前提下，把 session/run 级动态记忆整理给 Runner。

## 目标

让 Runner 获得“足够有用但不过量”的短期记忆，而不是自己拼历史。

## 职责

- 读取 session 级短期记忆
- 压缩最近任务与回答摘要
- 组织 memory context
- 在 run 结束后回写可保留记忆

## 不负责

- 不读写 workspace 文件
- 不执行 shell
- 不调用模型
- 不直接接数据库或向量库

## 当前阶段

本层先做进程内、session 级短期记忆；长期记忆和外部存储不是当前阶段目标。
