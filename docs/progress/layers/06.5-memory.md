## 2026-05-19 / Phase 6.5 / 从摘要记忆升级到 working memory

### 当前目标

### 本次完成

- Memory 新增 `workingSet`
- `workingSet` 新增 `focusedFilePath`
- `workingSet` 新增 `focusedOpenableHtmlPath`
- `workingSet` 新增 `recentFilePaths`
- `workingSet` 新增 `openableHtmlPaths`
- Memory 从 `write_file` 抽取文件产物
- Memory 从 `read_file` 抽取最近读取文件
- Memory 从 `patch_file` 抽取最近修改文件
- Memory 从 `open_browser` 抽取最近打开的 html
- Memory 从 `list_files` 抽取可打开 html 候选
- Memory 从 `shell_exec cp/mv` 抽取复制/移动后的目标文件
- Memory summary 改为显式输出 focused artifact 和 openable html artifacts
- system prompt 新增“优先使用 working memory，不要重复扫描 workspace”规则

### 当前状态

- 已完成：结构化 working memory 主体能力
- 进行中：更多工具结果仍可继续接入 memory 抽取
